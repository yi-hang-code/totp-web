# TOTP-Web · 纯前端 TOTP 身份验证器

> 单文件 · 零网络 · 可离线 · MIT 开源
> Single-file · zero-network · offline · MIT licensed

一个**纯浏览器前端**的 TOTP（RFC 6238）身份验证器。所有计算都在本地完成，不依赖任何服务器、不上传任何数据，可直接用浏览器打开使用。
A **pure browser front-end** TOTP (RFC 6238) authenticator. Everything is computed locally — no server, no upload — just open it in a browser.

---

## 功能特性 · Features

- **多账户管理**：添加 / 删除 / 编辑多个 TOTP 账户，卡片网格展示。
  Multi-account management with a responsive card grid.
- **两种录入方式**：手动输入 Secret，或粘贴 `otpauth://` 链接，或扫描 / 上传二维码。
  Add by typing a secret, pasting an `otpauth://` URI, or scanning / uploading a QR code.
- **主密码加密**：用 PBKDF2 + AES-GCM 派生密钥加密本地存储的 Secret，密码不落盘；闲置 5 分钟自动锁定。
  Optional master password (PBKDF2 + AES-GCM) encrypts stored secrets; the password is never persisted; auto-locks after 5 idle minutes.
- **扫码兜底**：优先用浏览器原生 BarcodeDetector，不支持时回退到内联的 jsQR，保证桌面 Firefox / Chrome 也能扫。
  Native `BarcodeDetector` first, with inlined jsQR as a fallback so desktop Firefox / Chrome can scan too.
- **零依赖单文件**：构建后是一个独立 HTML，可离线运行，可随意复制分发。
  The build output is one standalone HTML file that runs offline and can be shared freely.

## 安全模型 · Security Model

- **数据不出本机**：所有 TOTP 计算、加密、存储都在浏览器内完成，页面通过 CSP 与 `connect-src 'none'` 主动禁止任何网络请求。打开页面时可看到实时「零网络」自检计数。
  All computation, encryption, and storage happen in the browser. A strict CSP with `connect-src 'none'` actively blocks any network request; the page shows a live "zero-network" self-check counter.
- **主密码不存储**：密钥由主密码经 PBKDF2-HMAC-SHA256（310,000 次迭代）派生，`extractable: false`，永不以明文出现在任何地方；忘记密码只能清空本机数据重设。
  The key is derived from your master password via PBKDF2-HMAC-SHA256 (310,000 iterations) and is `extractable: false`; it never exists in plaintext. Forgotten passwords require wiping local data.

## 快速开始 · Quick Start

**直接用（无需构建）** · **Use directly (no build needed):**
下载发布版的 `dist/index.html`，双击用浏览器打开即可。
Download the released `dist/index.html` and open it in any browser.

**或自行构建** · **Or build it yourself:**

```bash
npm install         # 安装开发依赖（jsdom / terser / jsqr）
npm run build       # 生成可读版 dist/index.html（便于审计源码）
npm run build:min   # 额外压缩 HTML/CSS/JS，生成用于分发的最小版
```

- `npm run build` 生成的 `dist/index.html` 保留换行与缩进，方便你直接对照源码审查。
  The `build` output keeps newlines/indentation so you can audit it against the source.
- `npm run build:min` 在此基础上再压缩 HTML/CSS/JS（jsQR 已是压缩态），体积约 175KB，适合实际分发。
  `build:min` further minifies HTML/CSS/JS (~175KB) for distribution.

无论哪种方式，产物都是单文件、零网络；测试脚本永远不会被打进去。
Either way the output is a single offline file; test scripts are never bundled.

## 升级 jsQR · Updating jsQR

`tools/jsqr.min.js` 是 vendored 的压缩版 jsQR。**升级步骤 · Upgrade steps:**

```bash
npm install                 # 确保本地有 jsqr / terser
npm run build:jsqr          # 从 node_modules/jsqr 重新压缩生成 tools/jsqr.min.js
npm run build               # 重新生成 dist/index.html
sha256sum tools/jsqr.min.js # 记录新校验值，便于审计
```
