TOTP 动态口令

纯前端 · 零依赖 · 主密码加密后仅存本机浏览器

纯本地运行 本页面不会向任何服务器发送数据，Secret 永不离开这台设备
  • 无后端：页面没有任何服务端接口，口令由本机浏览器的 WebCrypto（HMAC-SHA1/256/512）在本地计算。
  • 零网络：自页面脚本运行以来，发起的网络请求 0 次（已覆盖 fetch / XMLHttpRequest / WebSocket / sendBeacon，可用 DevTools → Network 面板复核）。
  • 存储位置：账户与 Secret 只保存在本机浏览器的 localStorage（同源隔离、不上传），且强制使用主密码加密 —— 现在添加的任何账户，落盘一律是 AES-GCM 密文，解密密钥由密码当场派生、随即丢弃，页面关闭/锁定后本机只剩密文（仅本版本之前遗留的历史明文数据例外，页面会提示你一次性加密）。忘记密码无法解密，请用锁屏页的「清除本机浏览器加密数据」清空后重新设置。
  • 二维码：生成与识别都在本机完成 —— 绘制用内置编码器；识别优先用系统 BarcodeDetector（仅部分 Android/Chrome 可用），不可用时自动回退内置的 jsQR 解码库（Apache-2.0，已内联进本文件）。两者都不调用任何在线服务。
可直接粘贴 Google / Microsoft Authenticator 导出的 otpauth:// 链接，或手动输入 Base32 Secret。

请先设置一个主密码

Secret 会保存在这台设备的浏览器里。为防止任何人打开浏览器就直接看到，本工具要求先设置主密码：它只在本机加密你的 Secret，密码本身不会被保存。

  • 密码仅用于当场派生解密密钥，不会被保存，每次打开页面都要重新输入
  • 遗忘后无法找回 —— 只能清除本机浏览器数据并重新设置
  • 解锁状态闲置 {{min}} 分钟会自动锁定

设置完成后即可添加第一个账户

安全提示：Secret 以主密码加密后保存在本机浏览器的 localStorage，密码本身不保存、遗忘无法找回；解锁后明文只在内存中，闲置 5 分钟自动锁定。忘记密码请用锁屏页的「清除本机浏览器加密数据」清空后重新设置。
实现遵循 RFC 6238（TOTP）/ RFC 4226（HOTP 计数与截断）；时间取自本机系统时钟，若本机时间不准会导致验证码不匹配，请先校准系统时间。
